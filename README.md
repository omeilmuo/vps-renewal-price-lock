## 续费不涨价的三种实现方式

同样是“续费不涨价”，落到系统里有三种不同做法，对买家的约束条件也不一样。

**第一种，循环计费锁价。** 下单时把价格写进循环计费（recurring pricing），之后每一期账单由系统按这个价格自动生成，跟官网后来有没有调价无关。RackNerd 的促销套餐走的就是这条路，价格写在服务协议里，续费金额和首购完全一致。

**第二种，后台明示续费金额。** 搬瓦工在 Services → My Services → 对应 VPS 页面有一个 Recurring Amount 字段，直接显示每期要付多少。这个数字是已经定死的，不是估算。你不需要理解背后的计费逻辑，看这一栏就够了。

**第三种，终身循环折扣。** Jtti 的政策是首购享受的折扣价，在同周期续费时保持不变。年付买的，续费还选年付，价格不动；从年付改成月付，就按月付的正常价重新算。

LightLayer 的活动公告只承诺了“续费同价”，没有公开它属于哪一种实现。这不影响你的判断，下单之后在账单页能看到下一期的具体金额，那才是最终依据。买之前也可以直接问客服一句：同周期续费是否维持活动价，改周期怎么算。

## 四种会让锁价失效的操作

锁价锁的是“原套餐、原周期、原机房”这个组合。动其中任何一项，原来的价格就未必跟得过来。这四条前排文章大多没讲透，但它们直接决定你第二年会不会被涨价。

**改计费周期。** 搬瓦工从月付改年付，价格会按当前官网价重算，原来的低价可能就此消失；改短期（年付改季付）一般不影响。Jtti 的口径一致，年付改月付按月付正常价。LightLayer 这次促销允许季付、半年付、年付叠加折扣，如果你打算长用，一开始就选好周期，别中途改。

**升级配置要另购。** RackNerd 明确不支持把已购套餐的资源合并或迁移，1GB 想升 2GB 只能另开一台，新机器按新套餐当前价格走。所以选套餐时把未来一年的需求估准，买小了再折腾的成本比一开始多花的那点钱高。

**换机房不保留原价。** 同样以 RackNerd 为例，锁价绑定在那台机器的那个机房上，换机房等于换服务，按新价格走。对线路敏感的用户要特别注意，先测延迟再决定机房。

**换优惠码丢原折扣。** 搬瓦工首购用了优惠码，续费默认继续享受，不用重新输入；但一旦换新码，原来的折扣就没了，而且续费中途不能换码。LightLayer 的优惠码是按机型分开发放的，一个码对应一类产品，下单时用对码，后面别乱动。

## 忘记续费之后，机器还能救回来吗

价格不涨，不代表忘了付款就没事。三家商家的处理时间线差别不小。

搬瓦工 2026 年调整了账单政策，到期前 7 天生成续费账单并发邮件，账户有余额则自动扣款。到期日当天服务仍正常运行；账单生成后约 14 天未付，VPS 被暂停，付款可恢复；暂停后约一周，账单取消、VPS 彻底删除，数据无法恢复。从到期日算起大约 3 周缓冲期。

RackNerd 在到期前 14 天自动出账并邮件提醒，另外提供服务详情页的 Generate Renewal Invoice 按钮，可以随时手动提前生成账单，付完周期顺延一个完整周期，不重叠计费。也可以在 Billing → Add Funds 先充余额，账单出来自动扣。

Jtti 的规则不太一样：包年包月是预付费，关机不停止计费，只有删除实例才真正停止扣费。因为实例没删除，CPU、内存、存储和 IP 资源仍然为你保留。这一点对想“先关掉省钱”的人是反直觉的。

LightLayer 的宽限期和删除策略，活动公告里没有写。下单后建议把到期日写进日历，或者提前充余额。真到了暂停那一步，先看后台账单状态，账单还在就还有救。

## 什么情况下不值得续

续费不涨价是好政策，但它只保证你付的钱不变，不保证你付的钱花得值。三种情况下，续约反而是在为用不上的资源买单。

**配置买大了。** 4核8G 的机器，CPU 使用率常年低于 5%，这种配置对个人博客和小型企业站是浪费。按常见选型经验，个人博客 1核512M 就够（$2-3/月档），WordPress 企业站 1核1G（$5-6/月档），小型电商 2核2G（$10-15/月档）。先用小的，不够再升。

**月付常规套餐长期跑。** 上面算过，RackNerd 月付 1GB 一年 $215.88，年付促销 $21.99。数据搬迁几个小时的事，长期看省下的钱远超时间成本。

**只需要轻量资源却上了独服。** LightLayer 洛杉矶独服 $40/月、香港独服 $84/月，适合需要独享硬件、跑重型业务或对 IP 资源有要求的场景。跑个博客或代理，新加坡 $3.50 的云服务器就够，没必要为用不到的核数付费。
